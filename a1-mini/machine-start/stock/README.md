# A1 Mini – Stock machine start G-code

The files in this folder are **unmodified original G-codes from Bambu Lab**. They are kept as a reference to compare the customized versions against and to track Bambu's updates.

Do not edit these files. A new Bambu release is added as a new file next to the old ones.

## Source

All files come from the official Bambu Lab repository [bambulab/BambuStudio](https://github.com/bambulab/BambuStudio), folder `resources/profiles/BBL/machine/`. The G-code is the `machine_start_gcode` value of the JSON profile, written out as plain text. The date in the file name is the date from Bambu's own header line (`;===== date: …`).

This is the same G-code that Bambu Studio fills in by default for the A1 Mini with a 0.4 mm nozzle.
