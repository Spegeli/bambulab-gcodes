# Bambu Lab A1 Mini

Custom G-codes for the Bambu Lab A1 Mini (180 × 180 × 180 mm, bed-slinger, optional AMS lite).

## Customized G-codes

| Field | Latest version | Stock reference |
|-------|----------------|-----------------|
| [Machine start](machine-start/) | [v1.0.0](machine-start/machine-start-v1.0.0.gcode) | [20260513](machine-start/stock/machine-start-stock-20260513.gcode) |

All other fields use the Bambu Studio defaults.

## Printer facts used by the G-codes

| Item | Value |
|------|-------|
| Max bed temperature | 80 °C |
| Wiper | X 0 (edge) to X -13.5 (inside) |
| Silicone brush | Y 185, X -10–25 |
| Z homing spot | X 50, Y 175 |
| Calibration line | Y -2.4 (second line Y -4.2), X 68–113 |
| Motor currents during start | X 0.7, Y 0.9, Z 0.3 A |
