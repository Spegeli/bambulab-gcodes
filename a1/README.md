# Bambu Lab A1

Custom G-codes for the Bambu Lab A1 (256 × 256 × 256 mm, bed-slinger, optional AMS lite).

## Customized G-codes

| Field | Latest version | Stock reference |
|-------|----------------|-----------------|
| [Machine start](machine-start/) | [v1.0.0](machine-start/machine-start-v1.0.0.gcode) | [20260513](machine-start/stock/machine-start-stock-20260513.gcode) |

All other fields use the Bambu Studio defaults.

## Printer facts used by the G-codes

| Item | Value |
|------|-------|
| Max bed temperature | 100 °C |
| Wiper | X -28.5 (edge) to X -48.2 (inside) |
| Silicone brush | Y 262.5, X 20–65 |
| Z homing spot | X 128, Y 254 |
| Calibration line | Y -0.5 (second line Y 1), X 108–153 |
| Motor currents during start | X 0.65, Y 1.2, Z 0.3 A |
