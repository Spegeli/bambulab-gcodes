# A1 – Stock machine start G-code

The files in this folder are **unmodified original G-codes from Bambu Lab**. They are kept as a reference to compare the customized versions against and to track Bambu's updates.

Do not edit these files. A new Bambu release is added as a new file next to the old ones.

## Source

All files come from the official Bambu Lab repository [bambulab/BambuStudio](https://github.com/bambulab/BambuStudio), folder `resources/profiles/BBL/machine/`, and cover every distinct version in its git history. The G-code is the `machine_start_gcode` value of the JSON profile, written out as plain text with LF line endings. Up to 2025 it lived in `Bambu Lab A1 0.4 nozzle.json`; since 2026 Bambu keeps it in a separate `… template machine_start_gcode.json`.

The date in the file name is the date from Bambu's own header line (`;===== date: …`). This is the G-code that Bambu Studio fills in by default for the A1 with a 0.4 mm nozzle.
